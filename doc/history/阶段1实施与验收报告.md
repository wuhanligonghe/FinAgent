## 1. 本次交付

- 自研模型—工具—观测反馈循环；支持 Chat Completions 和 Anthropic Messages，按现有 `/anthropic` 配置自动选择协议。
- `chat` 连续输入、同任务澄清、取消后继续；`run` 保持单次入口。等待澄清不消耗任务执行时间，调用预算不重置。
- 11 项注册工具，新增 `load_skill`、`calculate_market_metrics`、`export_research_result`，不提供任意 Shell、URL 或文件写入。
- `closing_review` Skill 按需读取、版本/摘要追踪，随安装包交付。
- 确定性计算只从当前任务登记结果读取价格，核对证券、币种、单位、来源、口径、原始字段及前一条可比记录；缺前收则补查，不混用当前快照和历史日线。
- 草稿只能写任务内固定路径；最终 JSON/Markdown 由宿主核验后导出，包含计算路径、来源限制和原始响应。
- 边界 `state.json`、消息、事件、原始材料、完整规范结果、调用计数、实现/提示词/工具摘要、可得 Token 和未知费用 `null`。
- 项目 `.env` 读取已接入，环境变量优先，不执行插值或把凭证写入产物。

## 6. 运行与复现

在实际项目目录 `FinAgent` 中执行；`.env` 放在 `finagent.toml` 同目录，模型凭证仅在本机保存。

```powershell
.\.venv\Scripts\python.exe -m finagent chat
.\.venv\Scripts\python.exe -m finagent run "对贵州茅台2026-10-16做收盘复盘，给出收盘价、前收及涨跌幅和来源。" --symbol 600519.SH
.\.venv\Scripts\python.exe -m finagent evaluate --mode replay
.\.venv\Scripts\python.exe -m finagent evaluate --mode online
.\.venv\Scripts\python.exe -m finagent evaluate --mode model
.\.venv\Scripts\python.exe -m finagent evaluate --mode model --cases D2 D3
.\.venv\Scripts\python.exe -m finagent evaluate --mode audit
.\.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
```

模型验收会实际调用模型并发生用量，联网结果随源站变化；audit 只读取已保存证据，不发请求。日期和报告期示例要按实际目标调整。运行数据默认被 Git 忽略；复制项目演示时需另外保留 `.finagent/` 原始证据或重新运行在线检查，不能只复制摘要冒充证据。

## 7. 保留的限制与阶段二输入

- 仅沪深 A 股；两个样本不代表其他证券都有同样覆盖。日线最多约 800 条，新闻近期第一页，不证明任意历史完整性。
- 交易日历、供应商最终状态及财务重述版本没有独立证明，日线 finality 保持 unknown；不以本机时间推断完整收盘。
- 三表为聚合数据，金额单位沿接口约定并保留原字段，不能充当完整年报原文；营业收入与营业总收入分开，缺失不互代。
- 宿主校验工具、关键计算及引用，不自动证明每句自然语言断言；没有完整财报知识库、受限财务多步程序或微调。
- 每个新 chat 目标独立，澄清可续当前任务；跨任务记忆、自动压缩和进程中断后的完整续跑留在后续阶段。
- 同步网络的取消在安全边界生效，在途请求依赖超时结束，不提供强杀调度。
