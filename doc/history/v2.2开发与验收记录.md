## 已交付的行为

- 普通聊天只分流问答、查询、报告读取和专项分析；不从“深入”“全面”等词推断深度模式，没有维度则澄清。
- `/research` 菜单和 `research --mode deep_research|full_decision` 由宿主登记选择，摘要显示阶段、范围和预算。只打开配置不创建研究；过期、伪造、修改范围或重复使用的选择被拒绝。
- deep_research 实际执行多空交替和研究经理裁决后结束，计划中没有交易员／风险／组合经理节点；full_decision 保留完整角色链。
- 选择来源和 mode 写入新版本 scope／hash 及启动事件，研究工具只能消费本轮宿主范围，普通工具不能创建深度授权。研究完成后回到普通聊天，不从 last_research_id 继承模式。
- 新研究 scope 使用 workflow_version=2.2；历史任务不改原 scope／hash。恢复需要明确 ID 和可核验启动记录，且继续受实现／模型指纹和剩余预算限制。自然语言恢复意图只提示显式恢复命令，不自动消耗预算。
- nlu22.1 移除 depth／workflow_preference；共享伴随包0.2.0保留8个分类头、29标签实体头。结构化研究参数完整时，无需加载 NLU 权重。

重点实现位于 `research/selection.py`、`research/menu.py`、`research/workflow.py`、`decision_coordinator.py`、`decision_runner.py`、报告模块、`nlu/`、CLI/chat 和委托工具。没有引入 Web 前端或 LangGraph。

## 外置 training

独立源码仍位于 `../training/macbert_nlu`。新 schema、模型结构、解码、数据校验、训练、校准、评估、导出、包验证和配置已同步；训练根目录和详细 README、标注规范一并更新。

| 数据状态 | 条数 |
|---|---:|
| 默认训练候选 | 1360 |
| 默认验证候选 | 320 |
| 默认回归测试候选 | 320 |
| 当前候选合计 | 2000 |
| 旧隔离记录（已从新目录删除） | 620 |
| 人工核验／正式独立验收 | 0 |

初次迁移交付为1380条默认候选及620条隔离记录。按用户追加要求，本次删除新目录的旧隔离记录及其宿主样例文件，保留1380条，新增620条普通NLU候选，合计2000条。新增来自62个表达家族、310种基础表述及变体，不声称为620种独立语义。当前migration_audit.jsonl仅含2000条现有样本的ID、集合、家族及来源，不保存被删记录或旧字段原值。depth、workflow_preference及其他执行模式字段直接移除，不保留null。

原500／1500／2000历史语料保持不变，本次核对39个历史文件哈希。原outputs与base_model不在同步写入范围。新manifest数据版本为bootstrap_2000_nlu22_v2，目录路径保持兼容；候选配置改用data2000-v2新输出目录，不能resume旧1380条实验。详细检查见`.finagent/v22_validation/dataset_2000_refresh.json`。

新增两组可直接在服务器选择的候选配置：`nlu22_candidate_unweighted.yaml` 和 `nlu22_candidate_weighted.yaml`。后者使用仅来自 train 的 inverse-sqrt 类别权重；记录原始／最终权重、逐轮学习率、warmup／优化器步数、BIO及分类与实体支持数。正式入口默认 `3090_nlu22.yaml`，需要用户准备人工数据；候选诊断不会通过校准和发布门槛。

最佳模型改为固定 val_selection_score，完整帧仍单列；准入准确率统计误接受的应澄清输入，覆盖率分母为应接受输入。支持基于相同保留字段的已保存预测对照，缺少旧预测则明确不可比。独立人工覆盖、语义质量门、宿主边界报告与 GPU／CPU 一致性和真实本地性能分别验收。

旧语料工具使用隔离 legacy21 合同，仅作旧数据维护。新审核脚本 `review_nlu22.py` 不会自动批准；另交付独立验收格式指南。新训练不能 resume 原十头 checkpoint。
