## 安装与运行

Python 3.11+。建议新建独立环境，避免使用其他机器复制来的旧虚拟环境。P0 开发初期使用 Python 3.13.9 与项目目录内依赖；随后已备份并重建当前 `.venv` 为本机 Python 3.11.15，详见[启动故障与环境修复](../guides/RUNNING.md)。

```powershell
python -m venv .venv-p0
.\.venv-p0\Scripts\python.exe -m pip install -e '.[pdf,calendar]'
.\.venv-p0\Scripts\Activate.ps1
.\.venv-p0\Scripts\python.exe -m finagent tools
.\.venv-p0\Scripts\python.exe -m finagent chat --session research
```

保留原有 `finagent.toml`、本机 `.env` 与模型协议设置。支持直接查询、持续聊天和独立工具调用，不依赖前后端页面。

```powershell
# 获取并导入本次人工核对的公开完整年报；下载失败时保留失败状态。
python scripts/prepare_public_samples.py

# 人工导入其他完整报告/公告；模型没有文件路径或任意URL权限。
python -m finagent import-document 'D:\资料\报告.pdf' --manifest 'D:\资料\报告元数据.json'
python -m finagent library

# 财务程序：使用原文证据，不需要微调模型。
python -m finagent run '查询贵州茅台2024年度营业收入同比增长率及合并全部净利润净利率' --as-of '2025-05-01T23:59:59+08:00'

# 完整复盘会检查日期、基准、历史长度和供应商最终状态。
python -m finagent run '对贵州茅台2026-10-16做收盘复盘，并给出可验证的研究建议'

# 多次一次性运行也可选择共享范围记忆；每轮重新取证。
python -m finagent run '查询贵州茅台2024年报营业收入' --session research
python -m finagent run '那上一年呢' --session research
python -m finagent run '换成宁德时代' --session research

# 恢复保持原截止与预算，不代表刷新最新事实；已完成任务拒绝重复恢复。
python -m finagent resume '<32位任务ID>'
python -m finagent chat --session research
# 在聊天中输入 /resume 任务ID，可继续待澄清或取消的旧任务；/forget 删除会话记忆。

# 长期偏好只接受用户显式设置；不把行情保存在偏好中。
python -m finagent session research --preference display_unit --value 亿元
python -m finagent session research --preference display_unit
python -m finagent session research --forget
```

示例日期仅用于复现。持久化时间含时区，沪深市场使用 Asia/Shanghai。日历超出已安装版本的覆盖时明确拒绝，不能回退为“周一至周五”。

普通财报查询先 `resolve_task_scope` → `search_evidence`，需要时 `read_document`；计算由主模型填写 `generate_program` 的 `fact_ids` 和 `steps`，然后调用 `execute_program`。这不是第二个 Agent，也没有执行生成的 Python。`verify_analysis` 检查结构化事实、程序值与证据引用，自然语言的全部语义仍需人工抽查。

`DocumentImport` 的示例见 [公开样本清单](../public_samples.json)。事实标注必须指出数值、指标名、期间、单位、币种及合并范围在原文中的定位。标注通过结构和数值核验，不能替代人工确认原文会计含义。只有日期的可信披露按次日零点保守可用；不可信披露时间使用首次观测时间。训练答案 JSON 不属于可导入原文格式。

## 行情完整性和显式回放

当前新浪在线日线没有可信最终完整标记。因此，能够返回同源涨跌、均线与基准指标，但**不能把在线演示称为已确认最终完整的收盘复盘**；相关任务保持 `partial`。不能以本机已经超过 15:00 代替供应商完整证明。

另提供 `import-market 行情.json --manifest 元数据.json`，只供人工导入原始行情记录。记录格式为 `[{"day":"2024-04-30","open":10,"high":11,"low":9,"close":10,"volume":100,...}]`。元数据对应 `MarketImport`：`instrument`、`benchmark`、`source`、`source_url`、带时区 `fetched_at`、可选 `finality_field`、`synthetic`。其中 `finality_field` 必须指向原始每行确实为布尔 `true` 的供应商字段，不能在元数据中制造最终标记。

通过 `get_market_data/get_benchmark_data` 的 `mode="replay"` 使用。回放与在线分别标记；缺少原始完整标记仍为未知。归一结果的完整标记被修改也会在原始证据复核时拒绝。公司行动或交易日缺口会暂停受影响趋势比较；当前公司行动检测覆盖已导入资料，不代表全市场完整公司行动数据库。
