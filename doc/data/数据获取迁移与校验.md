Trading 的 mootdx/TCP、同花顺盈利预测/热点/北向、市场快讯、资金流和龙虎榜暂未整体迁入。这些是后续候选适配器，不是已经接通的本次工具。未把 Trading 的 Web 服务、LangGraph 流程、报告字符串接口或模型配置复制为本项目依赖。

迁移基于本地 Trading 代码，保留根目录 `LICENSE` 和 `NOTICE` 及适配文件的来源说明；其中上游为 Apache-2.0。learn-claude-code 仅作为循环和注册分发思路参考，本项目未迁入它的 Shell 执行工具。

## 2. 首批工具

| 工具 | 输入重点 | 结果与限制 |
|---|---|---|
| `resolve_entity` | 名称或代码 | 本地精确名称/别名映射；未命中则在线搜索沪深 A 股；唯一精确匹配自动绑定，多候选或近似匹配展示名称供确认 |
| `get_quote` | 证券、可选指定来源 | 腾讯优先、新浪备用；同一来源提供价格与昨收，当前快照不能用于历史 |
| `get_daily_bars` | 证券、起止日期、不复权 | 新浪最多约800条，筛选窗口；不返回截止日当天条目作为完整日线 |
| `get_financial_statements` | 证券、`income/balance/cashflow`、报告期、数量 | 聚合三表、已映射指标和原字段；无完整原始年报，历史重述版本未核验 |
| `get_company_profile` | 证券 | 新浪F10当前主资料页；页面标题与证券代码匹配，不支持历史回填 |
| `get_stock_news` | 证券、起止日期、数量、可选来源 | 东方财富优先、新浪备用；仅近期第一页，按发布时间过滤，空结果不能证明不存在新闻 |
| `read_evidence` | 本任务证据ID、字符偏移、长度 | 原始字节按已记录编码解码或读取完整规范JSON；不接受路径 |
| `calculate_market_metrics` | 本任务结果 ID、目标日、可选前收结果 ID | Decimal 计算，核对原始价格、相邻记录、证券与口径 |
| `export_research_result` | 结构化回答和实际证据/计算 ID | 固定任务内路径草稿；宿主另外核验终态 |
| `ask_user` | 具体问题 | 待澄清后暂停依赖操作；这是循环控制工具，不负责发送外部消息 |

默认名称目录只含贵州茅台、宁德时代、美的集团及少量别名，未命中的名称会查询东方财富证券搜索 `https://searchapi.eastmoney.com/api/suggest/get`（固定 `type=14`，筛选沪深 A 股及一致的市场、类型和代码字段）。该搜索为本次独立新增，未从 Trading 迁入。原始响应及字段位置保留，搜索不等于历史名称或上市状态核验；查不到不能断言公司未上市。可配置自己的 `securities_file` 扩充全称/别名；六位代码输入仍不依赖名称目录。

## 3. 三层校验

**调用前**：白名单、JSON结构、额外字段拒绝、证券与市场、起止日期、窗口、截止时间、主任务证券、预算、取消、证据ID权限。

**解析时**：腾讯和新浪行情变量/代码匹配；正价格和非负量额；OHLCV关系；非有限值不进入数值；重复冲突日线拒绝；财务结构、科目重复、币种和原字段标签；新闻结构、链接协议和发布时间。

**结果后**：统一 `Observation` 合同、来源及原始快照、获取时间保留、历史截止过滤、空覆盖/失败/部分可用区分、缓存过期标记；结束时再核验必需工具及引用。来源不回显证券身份时明确标记按请求参数关联，不宣称已经独立核验。

统一结果包含 `status/data/source/source_url/fetched_at/data_time/market/symbol/currency/units/price_basis/snapshot_id/snapshot_ids/result_id/cache_hit/stale/warnings/error`。

- `ok`：当前合同满足且没有已知警告。部分本地读取工具可返回此状态。
- `partial`：有可用数据但存在覆盖、时效或独立核验限制；此次公开数据工具通常属于这一类。
- `empty`：在当前接口和时间范围内没有可用条目或已映射指标；不等于网络失败。
- `error`：调用拒绝、来源失败、结构或数据校验失败；用 `error.code` 区分原因。

缓存为进程内缓存：报价30秒、日线60秒、财务6小时、公司资料24小时、新闻5分钟。财务/新闻的截止时间参与缓存键，优先保证不同截止不能串数据，因此跨任务复用有限。过期刷新失败且有旧值时返回 `partial + stale=true`；预算和取消错误不能借缓存继续执行。

## 4. 财务、时间和完整性约束

- 利润表、现金流按年初累计；资产负债表按期末余额。归母净利润与净利润分别映射，缺失不互相替代。
- 当前指标映射包括营业收入、营业总收入、净利润、归母净利润、基本EPS、总资产、总负债和经营现金流净额。现金流 `MANANETR` 已根据实际响应的原文标签核验映射。
- 金额沿用 Trading 对该新浪接口的列报币种“元”口径，并在结果中说明仍待原始财报逐项比对；不能把聚合字段等同于完整原文证据。未识别币种直接拒绝，不静默使用人民币。
- 财报/新闻提供日期级披露时，保守可用时间为次日零时；无可验证时间或晚于截止的材料排除。当前下载到的财务版本仍可能包含后续重述，不能据此承诺严格历史点时数据。
- 日线始终保留 `finality=unknown`。未接交易日历和源站最终状态，不用本地“已过16点”推断收盘完整，也不把周末数据自动判为停牌或滞后。
- 新闻按条目自己的时间过滤，不把列表第一条时间复制到所有链接；摘要是外部数据，不是系统指令。
- 原始响应保存后再解析；HTTP错误页及解析失败响应也有快照。网络连接失败无响应时记录错误和请求次数，不伪造快照。

## 5. 后续接入约定

新增来源先在 `endpoints.py` 登记 HTTPS 地址和主机，再实现供应商适配器、规范输出和独立校验，最后在服务层选择启用。不能仅因 HTTP 200 就标记业务接入成功。

感知数据服务保持独立，将来需要 MCP 时，可以在这层之上增加协议适配；不重写抓取代码，也不让 MCP 接管本项目的 Agent Loop。

阶段一最终样本冻结为 `600519.SH`、`300750.SZ`；两只证券主备报价、日线、利润表和新闻共10项在线检查均有数据及原始快照。完整时间、期间和限制见[阶段报告](../history/阶段1实施与验收报告.md)。营业收入 BIZINCO 与营业总收入 BIZTOTINCO 分开映射，缺失不互相替代。
