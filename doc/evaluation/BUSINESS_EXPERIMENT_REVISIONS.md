# 首次评测的版本与分析修订

原推理清单、模型回答、usage和结果均保留在 `.finagent/business_experiments_v1/live_pilot/`，没有用后来的代码重新生成“原始结果”。

1. 首轮使用 `business-benchmark-v1`，在开发集3个case上执行直接模型、无任务表示Agent、完整Agent。三者各3组完成，共34次模型调用。没有运行留出集或真实深度研究。
2. 首轮之后补充了正文金额审计，并区分“正文金额未列入claims”和“正文金额没有可见原文依据”。对原回答离线重新评分，分析目录带 `posthoc_analysis=true`、原推理源码摘要和新评分源码摘要。没有新增模型请求。
3. 小样本bootstrap的退化区间增加描述性提示，不把 `[0,0]` 当成等效检验。
4. 数据合同自检发现同比增长率请求标签应使用 `%`，而不是默认金额单位。候选数据修正为 `business-benchmark-v1.1`，新增标签一致性检查。所选3个pilot case本身没有改动；原推理仍归属于原冻结数据版本，不改写为v1.1完整结果。
5. 留出集保持未测试状态，准备阶段也不展示检索成绩；先审核标签再运行。开发查询和扩展词是同阶段编写，不能把开发集检索分数作为独立泛化证据。
6. 后续实验增加完整包源码快照和逐调用消息/schema归档。首次pilot没有这两项完整归档，保留其原有限制，不补造当时的源码和请求文件。

后续若调整模型提示或评分规则，应新建实验/分析目录，保存相应摘要和变更理由，不能仅保留最好的一次运行。
