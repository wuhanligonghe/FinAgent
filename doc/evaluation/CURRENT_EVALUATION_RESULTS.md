# 当前Agent候选集实测结果

日期：2026-11-03。本次使用最终冻结版本、原候选标签和原阈值，完整运行98组、118轮验收候选数据。没有将未审核标签标成独立审核通过，没有修改提示词或金标追求本次分数。评测数据已用于开发诊断，之后不得再称为未见测试数据。

后续新增了[最终答案事实规则门禁](../security/FACT_CHECKING.md)。以下数字属于本次原冻结版本，不包含这项后续改动，不能当作新版本的质量或幻觉率结果。

之后又接入[注入与输出泄露防护](../security/PROMPT_INJECTION_DEFENSE.md)，以下分数同样不覆盖该机制，不是注入攻击成功率测试结果。

## 主要问题

前置分类中，行情、财务、新闻类别F1分别为93.33%、91.30%、91.89%。记忆类别5条均未正确完成分类，其中部分返回无效输出合同而进入兜底；研究类别召回率75%，存在将研究启动误作普通分析、将已有报告追问误作纯概念的问题。也有政策原文、公告等额外多选类别的情况，其中部分合理性需要独立标注审核，原始分数不因此事后修改。

完整链路有23轮未通过：17轮模型调用预算耗尽、1轮工具调用预算耗尽、2轮重复失败无进展、1轮目标对象不符、1轮暂停状态未更新、1轮未成功调用要求的新闻工具。两个可复核的任务理解问题是：上证指数切换为平安银行后目标对象为空；“先暂停这个分析”后状态仍为open。本次禁止工具和研究启动次数检查均通过，但这不是所有安全属性已穷尽验证的结论。

## 评测边界和成本

- 完整链路保持新Qwen分流开启，使用真实主模型deepseek-flash。金融工具走冻结合成HTTP和原文资料，研究执行为stub，不代表真实市场分析或报告质量。
- 逐轮模型调用上限10次、工具20次、活动执行180秒；生产项目配置的模型调用上限为40次。预算耗尽结果只说明在本测试预算内未完成，不能据此断定放宽预算后仍会失败，也不应从统计中删掉它们。
- 真实主模型历史与独立分类模式的用户历史不同。分类和全链路数值属于两个实验，不是同一条链路中可直接相乘的成功概率。
- 分类运行118次模型调用；完整链路684次（含Qwen），总计802次。完整链路服务商报告输入7,915,742 token、输出224,196 token，包含缓存上下文计数，不据此推算实际费用。
- 标签为开发辅助编写且未经独立审核；纯自然语言、财务数字与引用质量仍需按人工规范逐条审阅。自动通过率不能冒充金融回答正确率。
