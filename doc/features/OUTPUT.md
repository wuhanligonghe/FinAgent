# v3 回复、停止与事实核验

默认输出自然中文，按用户问题调整长度；没有 FinalAnswer JSON、固定五维报告或固定主张数。保留助手实际输出与完整工具调用，兼容识别的旧 status/answer 包装只用于旧模型输出和研究适配，不授予事实核验状态。

普通非空、未过滤且协议完整的响应可结束当前回复，持续会话仍然保留。没有工具调用不等于整个目标完成：有明确 `/goal` 时，独立只读判断器检查实际结果，未满足则在同一会话继续，后台未完成则等待。判断出错、资源不足和不可完成不会标成成功。

`completed` 表示响应或运行正常完成；Goal achieved 表示完成条件被判断满足；两者都不代表金融正文逐句正确。[事实规则门禁](../security/FACT_CHECKING.md)会在交付前检查可识别的关键数字、日期和证券身份，冲突时要求修正，无法通过时不交付错误草稿。未解析的自由文本、观点与因果支持仍需语义审阅。不要根据状态或存在来源 ID 推断全文核验通过。

来源按证券、期间、可用时间、版本和时效管理。动态报价过期后不用于最新结论，同一财报可按条件复用；多公司比较保留各自输入，不能串用。部分覆盖、历史报告与未知最终性必须保留说明。

工具错误返回当前循环，允许纠参；输出截断不执行不完整调用，可有界扩充输出预算并续答。取消或中断关闭悬空工具配对，恢复不重放未知是否完成的动作。空响应明确失败。

工具大结果完整保存到当前会话 `outputs` 目录，上下文仅保留原文前 3000 个字符的 `preview`、全文路径 `full_output`、总字符数 `characters` 和回读说明。转存不调用模型生成摘要，也不读取或生成旧版 `.summary.json` 缓存；全文不截断。`read_output(path, offset, limit)` 继续按字符回读原文，默认 10000、单次最多 30000 个字符。历史对话继续使用独立的结构化摘要流程。

回读会跳过仍在当前上下文的已读前缀；返回的 `offset` 是实际位置，`requested_offset` 保留请求位置，继续读取使用 `next_offset`。完全重复时返回 `OUTPUT_ALREADY_READ`，归档后可重新读取。`read_evidence` 还会把回读记录 ID 追溯到已授权的原始证据，避免读取转义后的包装。详见[历史摘要预算与回读去重](CONTEXT_SUMMARY_BUDGET.md)。

`/sources` 查看本会话来源与失效信息，`/details` 查看 last_result、usage、账本、事实检查标记和存储位置。一般失败文案不展示内部协议码，诊断仍保存在状态和事件中。

归档定位使用 `search_output(path, query, offset=0, max_hits=5, context_chars=200)`：区分大小写的字面关键词匹配，返回 `hits` 中的命中起止字符位置、`snippet` 和 `snippet_offset`。将 `snippet_offset` 传给 `read_output` 可读取附近原文。所有偏移量均从 0 开始，按 Unicode 字符计数；搜索不支持正则或语义匹配，无命中可更换同义词。每次最多 20 个命中，每个片段前后最多各 500 个字符；`has_more` 和 `next_offset` 支持继续搜索。搜索与回读共用会话路径校验及旧路径迁移映射，不能通过路径或符号链接读取会话目录外的文件。搜索片段是原文，不是新的指令或实时证据。

旧研究 `result.json`、report 与消息格式由兼容适配保留。新版普通对话检查点、任务和事件由 Redis 主存储保存，会话 transcript 继续作为文件归档，不再每条发言生成独立普通 run。旧 `v3/runtime.sqlite3` 只保留作离线迁移/备份，见 [Redis 会话存储](REDIS_RUNTIME.md)。
