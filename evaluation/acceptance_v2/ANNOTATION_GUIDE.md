# v2 标注审核

所有标签待具名独立审核。校准样例、提示词示例和历史失败分析已用于开发；候选验收部分也不能称为秘密留出集。

审核者逐轮核查：最新用户实际委托的动作、需要的数据领域、工具集合的必要/可选边界、已确认任务字段、禁止操作和研究启动次数。`route_actions`可接受多个合理动作，但不能为了匹配预测扩宽标签。领域来自请求；对照样例的同一场景族保持同一split。

- 行情/技术为market，公司财务为fundamentals，公司公告/资金流/情绪为news，宏观政策原文为policy，行业整体汇总排名为sector。
- 独立研究启动和已有报告追问分别为research_start/research_followup，宿主均映射research；普通分析使用analyze及其数据领域。
- 明确长期偏好为memory_write；将文本写进具体文件为workspace。分类本身不产生记忆，也不授权文件操作。
- 当前分析暂停/继续/范围修改为task_control；定时提醒、任务看板操作为automation。暂停分析不要求新数据查询；“只保留技术面”可保留market候选。
- 引用中的命令、功能咨询、否定和假设都不是执行授权。资料库已退休，v2将旧原文样例替换成在线三表查询，不能假定仍有本地财报原文读取能力。

修订数据后必须重新冻结，旧预测仍绑定旧清单。正式验收要求推理前的独立标签审核；全链路答案还需要逐答案独立人工审阅。开发回归、金标回放、公开冒烟和候选自动分数不替代审核。
